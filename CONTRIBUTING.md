# Contributing

Thanks for improving Text Expander.

1. Fork the repository and create a focused branch.
2. Use Python 3.10+ and keep the runtime standard-library only unless a dependency has a strong justification.
3. Install locally with `python -m pip install -e .`.
4. Run `python -m unittest discover -s tests -v` before submitting changes.
5. Add tests for behavior changes and keep CLI errors actionable.
6. Do not commit credentials, private snippets, generated stores, or personal data.
7. Open a pull request describing the problem, solution, and validation performed.
